# AI 대화 선호 진단 (preference-survey)

AI가 어떻게 답해 주면 좋은지 설문으로 알아내고, 그 결과를 AI 지침(CLAUDE.md 등)에 넣을 문장으로 바꿔 주는 Claude Code 스킬입니다.

"짧게 써 줘", "먼저 물어봐" 같은 지시는 말로 하면 쉽지만, 실제로 마음에 드는 답과 다를 때가 많습니다. 이 스킬은 같은 내용을 한 가지만 다르게 쓴 두 답을 보여 주고 고르게 해서, 말보다 선택으로 선호를 찾습니다.

## 바로 해 보기

설치 없이 설문만 해 볼 수 있습니다. 이 저장소의 `survey.html`을 내려받아 브라우저로 여세요.

- 약 55문항, 15분쯤 걸립니다.
- 답은 그 브라우저에만 저장되고 어디로도 보내지 않습니다.
- 끝나면 축별 위치, 신뢰도, 지침 초안이 나옵니다. 지침 초안은 ChatGPT의 맞춤 설정이나 Claude의 프로젝트 지침에 그대로 붙여 넣어도 됩니다.

## 무엇을 묻나

| 묶음 | 내용 |
|---|---|
| 축 11개 | 길이, 결론 순서, 묻기와 진행, 표·목록, 확인 보고, 이모지, 단정 정도, 설명, 의견 내기, 선택지, 용어 |
| 말투 | 합니다체·해요체·메모체·반말을 상황별로 |
| 싫은 것 | "좋은 질문이에요", 자기 칭찬, 끝 요약 같은 습관 |
| 상황별 질문 | 애매하게 나온 축을 상황을 나눠 다시 묻기(예: 작은 일은 알아서, 발송·결제는 먼저 묻기) |

고르기 어려우면 "잘 모르겠다"를, 두 답이 다 마음에 안 들면 "둘 다 싫다"를 누르고 어떻게 고치면 좋을지 적습니다. 이런 문항은 점수에 넣지 않고, 적은 말은 추가 질문을 짤 때 씁니다.

## 답을 얼마나 믿을 수 있나

설문 한 번으로는 우연히 고른 답과 진짜 선호를 가리기 어렵습니다. 그래서 아래 장치를 넣었습니다.

- 같은 질문을 좌우를 바꿔 다시 묻습니다(재검사 일치율).
- 같은 축의 두 문항이 같은 쪽을 가리키는지 봅니다(반분 신뢰도).
- 말로 답한 선호와 실제로 고른 선호가 다르면 표시합니다.
- 늘 오른쪽만 누르기, 늘 긴 답만 고르기, 너무 빨리 넘기기를 잡아냅니다.
- 두 답의 글자 수를 15% 안으로 맞추고, 더 긴 쪽의 방향을 축마다 반반으로 섞었습니다. 길이 취향이 다른 축 결과에 섞이지 않게 하기 위해서입니다.

종합 신뢰도가 "참고용"으로 나오면 지침을 만들지 않습니다.

## Claude Code 스킬로 쓰기

Claude Code와 Node.js 18 이상이 필요합니다.

```bash
git clone https://github.com/hyunsungko/preference-survey ~/.claude/skills/preference-survey
```

그다음 Claude Code에서 "선호 진단 해 줘"라고 하면 됩니다. 스킬은 다섯 단계로 진행합니다.

1. **근거 모으기**(`collect.js`): 그동안 AI에게 한 지적과 요청, CLAUDE.md, 기억 파일에서 선호가 담긴 문장을 모읍니다. 근거가 없으면 기본 문항을 씁니다.
2. **설문 짜기**: AI가 모은 근거를 보고 문항의 상황을 사용자의 실제 일로 바꿉니다. 규칙은 `설계원칙.md`에 있고, `build.js`가 길이 균형·방향·개인정보를 검사해 어긋나면 설문을 만들지 않습니다.
3. **설문**: 만들어진 HTML을 브라우저로 엽니다.
4. **추가 질문**: 애매하게 나온 축과 고르지 못한 문항을 모아, AI가 추가 질문 설문을 만들어 줍니다. 생략해도 됩니다.
5. **반영**: 결과를 CLAUDE.md 「대화 선호」 절, 경고만 하는 글쓰기 검사 훅, settings.json 제안으로 나눠 보여 줍니다. 사용자가 승인한 줄만 넣고, 권한 설정은 건드리지 않습니다.

자세한 절차는 `SKILL.md`, 측정 설계와 계산식은 `설계.md`에 있습니다.

## 개인정보

- 설문 답은 브라우저에만 저장됩니다. 결과 코드는 사용자가 직접 AI에게 붙여 넣을 때만 전달됩니다.
- 1단계 수집은 이 컴퓨터의 Claude Code 기록만 읽고, 결과 파일(`signals.md`)도 지정한 폴더에만 씁니다.
  - 사람이 직접 친 말만 모읍니다. 다른 세션이나 시스템이 넣은 말, 붙여 넣은 남의 글은 뺍니다.
  - 텔레그램 같은 채널 메시지는 `--owner`로 지정한 사람이 보낸 것만 읽습니다.
  - 비밀번호·PIN·키·토큰이 든 문장은 빼고, 메일·링크·긴 숫자는 가립니다.
- `signals.md`에는 사용자가 했던 말이 들어 있습니다. 공유하거나 git에 올리지 마세요.

## 파일

| 파일 | 역할 |
|---|---|
| `survey.html` | 기본 문항으로 만든 설문(혼자 도는 HTML 한 장) |
| `items.json`·`deep.json` | 기본 문항 |
| `collect.js` | 1단계 근거 수집 |
| `build.js` | 문항 검사와 설문 HTML 만들기(`--init`·`--bank`·`--resume`) |
| `score.js` | 채점(화면과 도구가 같이 씀) |
| `decode.js`·`apply.js` | 결과 풀기, 지침 반영안 |
| `test.js` | 가상 응답자 시험(`node test.js`) |
| `설계원칙.md`·`설계.md` | 문항 규칙, 측정 설계 |

문항은 지금 한국어로만 되어 있습니다.
